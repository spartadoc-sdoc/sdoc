Quick startDémarrage rapide

Generate a key pair, encrypt, decrypt.Générer une paire de clés, chiffrer, déchiffrer.

# generate keys — bob.pub is shareable, bob.key stays privategénérer les clés — bob.pub partageable, bob.key privée
sdoc keygen -o bob

# encrypt a file for Bobchiffrer un fichier pour Bob
sdoc encrypt letter.pdf -p bob.pub -o letter.pdf.sdoc

# Bob decrypts with his secret keyBob déchiffre avec sa clé secrète
sdoc decrypt letter.pdf.sdoc -k bob.key -o letter.pdf
